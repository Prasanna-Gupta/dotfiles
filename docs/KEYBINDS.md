# Keys

`Meta` = Windows key.

## Plasma
| Keys | Action |
|---|---|
| `Meta` | App launcher |
| `Alt+Space` | KRunner: search apps, files, calculate, convert units |
| `Ctrl+Alt+T` | Terminal (kitty) |
| `Meta+E` | Dolphin |
| `Meta+V` | Clipboard history |
| `Meta+Shift+S` | Screenshot a region (Spectacle) |
| `Meta+W` | Overview of all windows |
| `Meta+L` | Lock |
| `Meta+Ctrl+←/→` | Previous / next virtual desktop |

## Tiling (Krohnkite, after `./install.sh tiling`)
| Keys | Action |
|---|---|
| `Meta+J` / `Meta+K` | Focus next / previous window |
| `Meta+Shift+J` / `Meta+Shift+K` | Move window next / previous |
| `Meta+H` / `Meta+L` | Shrink / grow master area ⚠ `Meta+L` is also Lock: rebind one of them |
| `Meta+Return` | Make the focused window master |
| `Meta+I` / `Meta+D` | More / fewer master windows |
| `Meta+F` | Float / un-float this window |
| `Meta+T` | Tile layout |
| `Meta+M` | Monocle (one fullscreen window, cycle with `Meta+J/K`) |
| `Meta+\` | Cycle layouts |

Change any of them: System Settings → Keyboard → Shortcuts → search "Krohnkite".
Turn tiling off: System Settings → Window Management → KWin Scripts → untick Krohnkite.

## kitty
| Keys | Action |
|---|---|
| `Ctrl+Shift+T` | New tab (same folder) |
| `Ctrl+Shift+Enter` | Split side-by-side (same folder) |
| `Ctrl+Shift+\` | Split top/bottom |
| `Ctrl+Shift+]` / `[` | Next / previous split |

## Shell
| Keys / command | Action |
|---|---|
| `Ctrl+R` | Search full history (atuin) |
| `Ctrl+T` | Fuzzy-pick a file into the command line |
| `Alt+C` | Fuzzy-cd into a subfolder |
| `z name` / `zi` | Jump to a frequent folder / pick interactively |
| `y` | yazi file manager, cd's to where you quit |
| `up` · `get pkg` · `un pkg` | Update (snapshots first) · install · remove |
| `quiet` · `balanced` · `perf` | ASUS power profile |
| `doctor` · `theme` | Health check · re-run colour sync |
